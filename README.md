# FoldWallpaper

Google Pixel 11 Pro Fold 向けのライブ壁紙アプリ。**画面の開閉**と**マナーモード**の2つの軸で、表示する壁紙を自動で切り替えます。

折りたたみ端末は内側と外側でディスプレイの形が大きく違うため、同じ画像を両方で使うと構図が破綻しがちです。また、人前で端末を開くときに表示されている壁紙を意識したい場面もあります。このアプリはその2つを、端末の状態から自動で判断して切り替えます。

## 主な機能

- **開閉に応じた出し分け** — 内側ディスプレイと外側ディスプレイで別々のフォルダを指定できます
- **プロファイルによる出し分け** — マナーモードの状態から「プライベート」「標準」を判定し、壁紙を切り替えます
- **フォルダ内からランダム表示** — 開閉のたびに別の1枚が表示されます（直前と同じ画像は避けます）
- **時間経過での切り替え** — 開閉しないままでも、一定時間ごとに別の画像に切り替えられます
- **壁紙を暗くする** — 内側／外側それぞれ0〜80%の範囲で調整できます
- **オフラインで完結** — 外部通信は一切ありません。実行時パーミッションも不要です

## プロファイルの切り替え条件

**マナーモードの状態だけ**で判定します。`AudioManager.getRingerMode()` の値を次のように対応させています。

| 端末の状態 | 適用されるプロファイル |
|---|---|
| 着信音あり（`RINGER_MODE_NORMAL`） | **プライベート** |
| バイブ（`RINGER_MODE_VIBRATE`） | 標準 |
| サイレント（`RINGER_MODE_SILENT`） | 標準 |
| 判定できない・想定外の値 | 標準 |

公共の場ではマナーモードをONにする、という前提に立った割り当てです。**着信音が鳴る状態のときだけプライベート**になります。

判定できない場合を含め、迷ったときは必ず「標準」に倒れる設計です。プライベートなのに標準が出るのは無害ですが、その逆は避けたいためです。

### 切り替わるタイミング

次のいずれかで別の画像に切り替わります。

1. 端末を開閉したとき
2. マナーモードを切り替えたとき（**壁紙が見えている最中でも即座に反映されます**）
3. 設定した時間が経過したとき（なし / 15分 / 1時間 / 6時間）

## 使い方

1. アプリを起動し、**フォルダ設定**を開きます
2. 「内側」「外側」それぞれに、**プライベート用**と**標準用**のフォルダを指定します（最大4つ）
3. 必要に応じて**暗さ**と**切替間隔**を調整します
4. **「ライブ壁紙に設定」**を押し、システムの壁紙選択画面で適用します

フォルダは `DCIM` や `Pictures` の下に作成してください。Android の制限により、`Download` の直下や `Android/data` は選択できません。

暗さの調整はプレビューを見ながら行えます。プレビューには壁紙と同じ暗さが反映されます。

### 情報画面

右上の「情報」から開きます。

- **プライベート判定の状態** — 現在のマナーモードと、適用されるプロファイル。この画面を開いたままマナーモードを切り替えると表示がその場で変わるので、動作確認に使えます
- **壁紙の描画領域** — 内側／外側の実測解像度。壁紙用の画像を作るときの基準になります（端末を一度開いて一度閉じると両方の値が揃います）

## 画面構成

設定画面は、表示しているディスプレイの幅に応じてレイアウトが変わります。

| 表示中の面 | レイアウト |
|---|---|
| 内側（開いた状態） | 内側・外側を横並びで同時に表示 |
| 外側（閉じた状態） | タブで内側／外側を切り替え |

## 動作環境

| 項目 | 内容 |
|---|---|
| 対象端末 | Google Pixel 11 Pro Fold |
| Minimum SDK | API 36 |
| 言語 | Kotlin + Jetpack Compose |

対象を1機種に絞っているため、互換分岐を持たない設計になっています。

### 他のFold端末で使う場合

開閉の判定に使うアスペクト比は [`DeviceProfile.kt`](app/src/main/java/com/yoshiaki21/FoldWallpaper/DeviceProfile.kt) に集約してあります。後継機や他のFold端末で使う場合は、このファイルの数値を書き換えるだけで対応できます（判定ロジック側の修正は不要です）。

実測値は情報画面で確認できます。想定レンジから外れている場合は、その旨が画面に表示されます。

## 注意事項

- **アプリをアンインストールするとフォルダへのアクセス権が失効します。** 入れ直した場合はフォルダの再指定が必要です（端末の再起動では保持されます）
- フォルダが空だったりアクセスできなくなった場合でも、直前に表示していた画像を出し続けます。壁紙が黒くなることはありません
- ロック画面とホーム画面で別の壁紙を出すことはできません（ライブ壁紙からは区別できないため）

## 開発

```bash
./gradlew :app:assembleDebug
```

```bash
./gradlew :app:testDebugUnitTest :app:lintDebug
```

設計上の判断や、調査して分かった Android 側の制約は [fold-wallpaper-spec.md](fold-wallpaper-spec.md) に記録しています。特に以下は同じ検討を繰り返さないよう詳しく残してあります。

- Android の「モード」機能（サイレント モード等）と連携できない理由
- Photo Picker の URI が永続化できない理由と、その回避方法
- 両ディスプレイの解像度を同時に取得できない理由
